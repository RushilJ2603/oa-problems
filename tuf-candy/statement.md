# Candy

`n` children stand in a line with rating `ratings[i]`. Give each child at least one candy; any child with a higher rating than an adjacent child must get more candies than that neighbour. Print the minimum total candies.

## Input
- Line 1: `n`.
- Line 2: `n` integers `ratings[i]`.

## Output
A single integer: the minimum total candies.

## Constraints
- `1 <= n <= 10^4`
- `0 <= ratings[i] <= 10^5`

## Examples
```
Input:
3
1 0 5
Output:
5
```
