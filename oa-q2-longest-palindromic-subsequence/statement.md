# Longest Palindromic Subsequence

Given a string `s`, return the length of the **longest palindromic subsequence** in `s`.

A *subsequence* is a sequence derived by deleting zero or more characters without changing the
order of the remaining characters. A *palindrome* reads the same forwards and backwards.

## Input
A single line containing the string `s` (lowercase English letters).

## Output
A single integer — the length of the longest palindromic subsequence.

## Constraints
- `1 ≤ |s| ≤ 1000`
- `s` consists of lowercase English letters

## Example 1
Input:
```
bbbab
```
Output:
```
4
```
One longest palindromic subsequence is `bbbb`.

## Example 2
Input:
```
cbbd
```
Output:
```
2
```
One longest palindromic subsequence is `bb`.
