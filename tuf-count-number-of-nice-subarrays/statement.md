# Count Number of Nice Subarrays

A subarray is *nice* if it contains exactly `k` odd numbers. Given `nums` and `k`, return the number of nice subarrays.

## Input
- Line 1: `n` `k`.
- Line 2: `n` integers `nums[i]`.

## Output
A single integer: the number of nice subarrays.

## Constraints
- `1 <= n <= 5*10^4`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= n`

## Examples
```
Input:
5 3
1 1 2 1 1
Output:
2
```
