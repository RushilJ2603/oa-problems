# Climbing Stairs

A staircase has `n` steps; you start at step 0. Each move climbs either 1 or 2 steps. Print the
number of **distinct ways** to reach step `n`.

## Input
A single integer `n`.

## Output
A single integer: the number of distinct ways to reach step `n`.

## Constraints
- `1 <= n <= 45`

## Examples
```
Input:
2
Output:
2
```
```
Input:
3
Output:
3
```
