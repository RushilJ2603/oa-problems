# Aggressive Cows

`nums` gives `n` stall positions; place `k` cows in stalls so that the minimum distance between any two cows is as large as possible. Print that maximum possible minimum distance.

## Input
- Line 1: `n` `k`.
- Line 2: `n` integers `nums[i]` (stall positions).

## Output
A single integer: the largest achievable minimum distance.

## Constraints
- `2 <= n <= 10^5`
- `2 <= k <= n`
- `0 <= nums[i] <= 10^9`

## Examples
```
Input:
6 4
0 3 4 7 10 9
Output:
3
```
