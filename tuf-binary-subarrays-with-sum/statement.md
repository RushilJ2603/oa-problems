# Binary Subarrays With Sum

Given a binary array `nums` and an integer `goal`, return the number of non-empty subarrays with sum equal to `goal`.

## Input
- Line 1: `n` `goal`.
- Line 2: `n` integers (each 0 or 1).

## Output
A single integer: the count of subarrays summing to `goal`.

## Constraints
- `1 <= n <= 3*10^4`
- `0 <= goal <= n`
- each element is 0 or 1

## Examples
```
Input:
7 3
1 1 0 1 0 0 1
Output:
4
```
