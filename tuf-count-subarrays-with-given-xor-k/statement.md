# Count Subarrays With Given XOR K

Given an integer array `nums` and an integer `k`, return the number of subarrays whose XOR equals `k`.

## Input
- Line 1: `n` `k`.
- Line 2: `n` integers `nums[i]`.

## Output
A single integer: the count of subarrays with XOR `k`.

## Constraints
- `1 <= n <= 10^5`
- `1 <= nums[i] <= 10^9`
- `1 <= k <= 10^9`

## Examples
```
Input:
5 6
4 2 2 6 4
Output:
4
```
