# Count Inversions

Given an integer array `nums`, return the number of inversions: pairs `(i, j)` with `i < j` and `nums[i] > nums[j]`.

## Input
- Line 1: `n`.
- Line 2: `n` integers `nums[i]`.

## Output
A single integer: the number of inversions.

## Constraints
- `1 <= n <= 10^5`
- `-10^5 <= nums[i] <= 10^5`

## Examples
```
Input:
6
2 3 7 1 3 5
Output:
5
```
