# 36 — DP optimizations: Convex Hull Trick, Divide-and-Conquer, Knuth

**Placement value:** Medium — almost never a literal OA template (Striver omits this entirely); shows up only in hard screens as “partition into \(k\) segments / jump with quadratic cost / merge intervals under \(n\sim 10^5\)”. Primarily a Candidate Master rating-builder and the natural next step after classic 1D / interval DP.
**Prereq topics:** Classic 1D DP & interval / range DP, prefix sums (for \(O(1)\) segment costs), monotonic deque / sliding-window extrema, basic geometry of lines (slope, intercept, intersection), binary search; comfort with \(O(n^2)\) DP that is “almost” linear in the transition
**Pattern in one paragraph:** You have a DP whose naive transition is \(O(n)\) per state (total \(O(n^2)\) or \(O(kn^2)\) / \(O(n^3)\)) and the cost is “nice.” **CHT:** transition looks like \(\mathrm{dp}[i]=\min_j(\mathrm{dp}[j]+a_j\cdot x_i+b_j)\) — each prior \(j\) is a line; maintain the lower/upper envelope (deque if slopes & queries are monotone; `multiset`/Li Chao if fully dynamic). **D&C opt:** layered form \(\mathrm{dp}[i][j]=\min_{k<j}(\mathrm{dp}[i-1][k]+C(k,j))\) with \(\mathrm{opt}(i,j)\le\mathrm{opt}(i,j+1)\) (often from quadrangle inequality on \(C\)) → compute each layer in \(O(n\log n)\) by recurse-on-mid. **Knuth:** interval form \(\mathrm{dp}[i][j]=C(i,j)+\min_{i\le k<j}(\mathrm{dp}[i][k]+\mathrm{dp}[k+1][j])\) with \(\mathrm{opt}[i][j-1]\le\mathrm{opt}[i][j]\le\mathrm{opt}[i+1][j]\) → \(O(n^2)\) instead of \(O(n^3)\). Spot: “split array into \(k\) contiguous parts,” “jump / cut with cost \(a\cdot b\) or \((h_i-h_j)^2\),” “merge adjacent segments / optimal BST shape,” \(n\) too big for \(n^2\) or \(n^3\).

## Must-internalize checklist (5-10 bullets)
- CHT recognition: rewrite so the \(\min/\max\) is \(\min_j(m_j\cdot x_i+b_j)\) (pull \(i\)-only terms out); each \(j\) → line \((m_j,b_j)\).
- Monotone CHT (deque): slopes inserted monotone **and** query \(x\) monotone → pop front (better line) / pop back (not on hull); total \(O(n)\). If only slopes monotone, binary-search the hull (\(O(n\log n)\)).
- Fully dynamic CHT: LineContainer (`multiset` of lines by slope) or **Li Chao tree** (segment tree storing one line per node) when inserts/queries are arbitrary.
- D&C opt template: for fixed layer, `compute(l,r,optl,optr)` — solve `mid`, recurse left with `optr:=opt`, right with `optl:=opt`; \(O(n\log n)\) per layer if \(C\) is \(O(1)\) (or amortized \(O(1)\) like YAMP).
- Quadrangle / Monge: \(C(a,c)+C(b,d)\le C(a,d)+C(b,c)\) for \(a\le b\le c\le d\) ⇒ \(\mathrm{opt}\) monotone — sufficient condition for D&C (and often Knuth).
- Knuth template: fill by increasing length; when computing \(\mathrm{dp}[i][j]\), only try \(k\in[\mathrm{opt}[i][j-1],\mathrm{opt}[i+1][j]]\); store \(\mathrm{opt}\) alongside \(\mathrm{dp}\); total \(O(n^2)\).
- Cost \(C(i,j)=\mathrm{sum}(i..j)\) (stone/file merge, Slimes) is the default Knuth-friendly cost; always prove \(\mathrm{opt}\) monotone before restricting the loop.
- Deque window max (F2 / Fireworks) is the “1D special case” of CHT — master it first, then generalize to lines.
- Many D&C problems also admit CHT (and vice versa) when \(C(k,j)\) is linear in a monotone key — know both tools.

## Where it appears in OAs / interviews
- Almost never “implement CHT from scratch” in a timed OA; if it appears, constraints are small enough for \(O(n^2)\) and they want the **recurrence** (partition into \(k\) segments, jump with \((h_i-h_j)^2\) cost) — still *recognize* when the opt would kick in.
- “Minimum cost to merge adjacent piles / matrix-chain shape” → interval DP; interviewers may ask why Knuth/QI would speed it up even if they only want \(O(n^3)\).
- “Split an array into exactly \(k\) contiguous parts minimizing a segment cost” → D&C-opt shaped DP (Bakery / Gondolas family); OA usually has tiny \(n\) or a simpler cost.
- Harder online assessments occasionally ask “maintain \(\min(mx+b)\) under online line inserts” as a data-structure prompt → Li Chao / LineContainer one-liner once you’ve done Igloo / Fair Nut.
